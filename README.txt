GIHAN NETHSARA WH — Personal Portfolio Website

QUICK PREVIEW
1. Extract this ZIP folder.
2. Open the gihan_nethsara_wh_site folder.
3. Double-click index.html to preview it in a browser. No Java/Python installation is required for this static site.

PUBLISH ONLINE (so people can find it)
The site files are ready, but the website is NOT online yet. To make it publicly available:
1. Ask a parent/guardian or trusted adult to help create/manage the hosting account if needed.
2. Sign in to a static website hosting service such as GitHub Pages or Netlify.
3. Upload/deploy the contents of this folder (index.html and assets folder).
4. The host will provide a public URL. To use a custom domain such as gihannethsara.com, register a domain and connect it in the hosting settings.
5. Search engines may take days or weeks to list the site. After publishing, submit the public URL to Google Search Console and request indexing. Search appearance is not guaranteed.

LOGIN / EDITING
There is no private login page in this package because this is a static portfolio website, not an account system. To change text/photos, edit index.html and replace files in assets (keep the filenames the same). To publish updates, upload/deploy the changed files again. Your hosting provider account is where you sign in to manage the published website.
